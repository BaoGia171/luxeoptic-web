## Chạy lại

Cần Python 3.9+, PHP 8.2 (pdo_mysql, mbstring), MySQL 8.0 với executable `mysqld`.
Script tạo bản sao source và MySQL datadir mới trong thư mục tạm, cổng localhost
riêng, import schema vào database thử; không đọc cấu hình DB cá nhân và không
kết nối database dự án đang dùng. Tài khoản root không mật khẩu chỉ ở instance thử
bind `127.0.0.1`. Tiến trình thử được dừng khi script kết thúc.

```powershell
python scripts/test-tv2.py --php C:/xampp/php/php.exe --mysqld C:/path/mysql/bin/mysqld.exe
```

Lệnh trên chạy 38 kiểm tra HTTP/database. Để chạy thêm 18 kiểm tra trình duyệt,
cài Playwright ở thư mục công cụ riêng (`npm install playwright`) và truyền:

```powershell
python scripts/test-tv2.py --php C:/xampp/php/php.exe --mysqld C:/path/mysql/bin/mysqld.exe --playwright C:/path/tools/node_modules/playwright --browser "C:/Program Files/Google/Chrome/Application/chrome.exe" --ui-assets D:/BTLWEB1-ui-effects
```

Trong lần chạy đã lưu, `--ui-assets` là checkout `feature/ui-effects` tại `b32b120`.
Chỉ 4 file chờ ghép (`theme.css`, `ui-effects.css`, `theme.js`, `ui-effects.js`)
được chép vào **bản sao thử nghiệm**. Không merge hoặc sửa CSS/JS chung trong nhánh TV2.
Script in đường dẫn thư mục artifact chứa results.json, log server và ảnh chụp.
Chỉ chia sẻ results.json và ảnh đã kiểm tra, không chia sẻ toàn bộ thư mục tạm
(có database, phiên thử và cấu hình thử).
