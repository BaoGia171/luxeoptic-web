## Cách tái hiện

Theo README cài PHP và MySQL. Chạy `python scripts/test-commerce.py --php <php.exe> --mysqld <mysqld.exe>`; thêm `--playwright <package> --browser <chrome.exe>` để chạy UI. Chạy `scripts/test-tv2.py` với cùng hai tham số; chạy `python scripts/test-upload-apache.py --xampp C:/xampp`. Mỗi script in thư mục ARTIFACTS cuối lượt. Script không dùng cấu hình database thật và luôn dừng process do chính nó tạo.
